# FRAME Finished Video Ad Implementation Plan

> **For agentic workers:** Execute this plan task-by-task in the current repository. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend a saved six-frame FRAME treatment into six durable Runway clips, an edited 30-second H.264/AAC MP4, and a refresh-safe final-player experience.

**Architecture:** Preserve the brief, concepts, Visual Bible, storyboard, image generation, treatment, and Convex storage. Add production direction to the existing storyboard response, isolate Runway behind a provider module, persist one idempotent production record per treatment, poll individual tasks through short requests, immediately copy ephemeral outputs to Convex, and assemble only after all six clips are durable.

**Tech Stack:** Next.js 16, React 19, TypeScript, Convex, OpenAI Responses/TTS APIs, Runway Gen-4.5 image-to-video, FFmpeg, Playwright.

**Spec:** Active user request “FRAME — AI Video Ad Production Master Prompt”.

## Global Constraints

- Video starts only after the explicit `Generate my ad` action.
- Never use deprecated OpenAI Sora video models.
- Six paid clip jobs are idempotent and successful clips are never regenerated by polling, refresh, or React rendering.
- One failed shot can be retried without replacing successful shots.
- Runway output URLs are copied to durable storage before being shown.
- Final delivery is browser-playable H.264 video with AAC audio in MP4.
- No timeline editor, billing, authentication, team features, provider UI, or Direct this shot.

## Self-review

- The plan preserves every existing product boundary and introduces only provider, job, media, assembly, and final-player modules.
- Paid work has an explicit gate, an atomic lock, deterministic keys, bounded concurrency, and smallest-layer retry.
- Provider URLs never become durable product assets.
- Creative Grammar and Motion Direction are wired into actual prompts, not documentation-only skills.
- Real completion remains false until a real six-clip production, final MP4 probe, browser playback, and production download pass.
